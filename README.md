## Featured Public Project

### [AHV Remote Console](https://github.com/MarcoCarvin/ahv-remote-console)

**Nutanix AHV · Go · Electron · Systems Integration**

A cross-platform desktop application for accessing and managing virtual machine console sessions on Nutanix AHV.

Key capabilities include:

- Independent console windows for virtual machines.
- Keyboard and mouse interaction, fullscreen mode, and ISO mounting.
- Session reconnection and diagnostic information.
- Bidirectional clipboard integration through the SPICE guest-agent channel.
- A local Go runtime integrated with an Electron desktop application.
- Authenticated communication between desktop and runtime components.

The project combines desktop application development, virtualization integration, and systems-level engineering.

## Engineering Principles

- **Architecture before implementation:** Define responsibilities, dependencies, interfaces, and trust boundaries.
- **Security by design:** Treat identity, authorization, and secure communication as core architectural requirements.
- **Controlled automation:** Keep automated operations constrained by explicit policies and authorization.
- **Operational accountability:** Make system behavior observable, changes traceable, and outcomes verifiable.
- **Maintainability:** Prefer clear interfaces, documented decisions, and reproducible processes.
